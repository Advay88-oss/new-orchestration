# Tier C - future / not built

Marketed as the destination but **not in code** (doc 06) - future tense only, and see [/rules/not-built.md](/rules/not-built.md) which blocks claiming them live:

- **Fiat on/off-ramp** (US ACH/wire/debit, Canadian Interac/EFT) - the critical blocker.
- **Real KYC** provider - endpoints exist, auto-approves outside production.
- **The Auri card** - no issuer, no code.
- **MCP server and CLI** - placeholder package names.
- **Remittance corridors**, no-account claim links, on-chain Boost leverage, mobile apps, Auri Jewels rewards.

**The honest frame:** the money engine (hard part) is done; the rails around it (fiat, KYC, card) are the current build.
