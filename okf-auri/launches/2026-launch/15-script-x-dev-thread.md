# Content: X thread — developer wedge (Phase 0)
**Audience:** fintech developers · **Funnel:** awareness→interest · **Objective:** API signups · **CTA:** read the docs / get a key

1/ Auri isn't just a gold app — it's an API. The same engine that buys, borrows, and moves allocated gold runs behind scoped keys. A fintech can offer gold without building a vault, a ramp, or a lending market. Live in private beta.

2/ One scoped key → buy / sell / borrow / repay allocated gold (XAUT), on Ethereum, through Morpho. Idempotent writes. `read` and `trade` scopes. The same rails the app runs on.

3/ The security model is the headline: every trade runs through an owner-approved, spend-capped session key. A leaked API key can't exceed its caps, reach another account, or move funds to an external address. Genuinely unusual for a financial API.

4/ Why it's the one part of Auri that's global today: no fiat rail, no KYC burden of its own — the integrator serves their own users under their own compliance. Gold buy/hold/borrow as infrastructure.

5/ Building something that touches gold? The API is the fastest way in. Read the docs, request a key. (Private beta, access-code gated.)
