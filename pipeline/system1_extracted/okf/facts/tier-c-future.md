# Tier C - future tense only

Things that do not exist yet. They may be discussed as intent and never in the
present tense.

The Agent Score is the live example: it stays future tense until sybil
resistance is designed, which is flagged as the top blocker ahead of all
messaging work. A present-tense Agent Score claim is a false statement about a
shipped capability.

**Test for this tier:** if a reader tried to use it today, would they find
nothing there?
