# Narrative arcs

Three competing positions, one per strategist. Assigned rather than chosen, so the agents must argue instead of converge.

* [Capital efficiency](/arcs/capital-efficiency.md) - collateral doing one job
* [Risk relief](/arcs/risk-relief.md) - surviving leverage, not acquiring it
* [Agentic credit](/arcs/agentic-credit.md) - agents can pay, cannot borrow
