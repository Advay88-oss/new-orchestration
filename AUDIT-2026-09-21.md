# Vanna GTM Operating System — Production Audit

**Date:** 2026-09-21 · **Method:** read-only code forensics + one live end-to-end run (`RUN_AUTO_20260921_180046`) + process/state inspection + industry benchmarking
**Mandate:** determine what actually happens at runtime, not what the documents claim.

---

## Executive Finding

> **Are all 13 agents genuinely functioning as production-grade agents?**

**No. Two make a real text-model call; one makes a real image call; ten are deterministic rule tables or literal Python dicts.**

The decisive evidence is a live run performed for this audit:

| Measure | Value |
|---|---|
| Wall-clock | 130.23 s, exit 0, banner: *"COMPLETE ACROSS ALL 13 AGENTS"* |
| Spend-ledger call delta | 178 → **182** (4 entries) |
| Genuinely metered text-model calls (proxy log) | **1** |
| Of which failed and fell back to hardcoded copy | **1** (Agent 06) |
| Agents whose output is read by any later stage | **4 of 13** |
| Agents that are literal dicts | 11, 12 (100%), plus 02-directive, 04-evidence, 07-blueprint, 08-reasoning |

Agent 01 (ingestion) and Agent 08 (image generation) do real work. Agent 06 is the only text brain, and in the audited run its call failed — the shipped copy came from a hardcoded template at `channel_adapter.py:157-213`. Across surviving run records, **20 of 25 runs shipped that same fallback copy verbatim**.

This is not a 13-agent system. It is a **single 746-line linear function** (`run_full_pipeline_cycle()`) with thirteen `print()` banners, one real LLM call, one image call, and elaborate telemetry describing work that did not occur.

## Data Lineage

**Not one factual claim in the shipped copy traces to a source.**

The audited run's copy asserts `~320ms Mercury`, `0.00014 XLM fixed gas`, `1.25x rebalance`, `1.10x floor`, `$50 EVM fees`. Traced backwards:

- They are **hardcoded string literals** at `gtm_content/channel_adapter.py:162, 170, 179-180`, used verbatim when the model call fails.
- When the model call *does* succeed, the prompt at `channel_adapter.py:125, 133` **instructs it to insert those exact numbers**. They are injected by the prompt, never looked up.
- A directive containing "partnership" is keyword-matched at `run_autonomous_gtm_master.py:200-207` and wrapped with **hardcoded** `source="canonical_db"`, `evidence_status="OBSERVED"`, `confidence="HIGH"`. **A typed prompt becomes high-confidence observed evidence in one hop.**
- `pipeline/state/evidence.jsonl` **does not exist**.
- `pipeline/state/scraped_social_posts.jsonl` is **not scraped** — `scraped_social_collector.py:23` defines `SEED_POSTS`, hand-written posts with invented engagement (`likes: 482`), profile URLs posing as post URLs, and pre-authored marketing fields. **No network call in the file.**

## Agent Communication Problems

Communication is **superficial**. There is no shared state, no challenge mechanism, no ability to inspect another agent's reasoning, request evidence, or reject a claim. Messages are not persisted and carry no provenance. Agent identities (`pubkey-01-...`) are decorative strings.

The intended relay exists (`gtm_os/event_bus.py`) and **the production pipeline bypasses it** — one publish call, after all thirteen stages finish.

Against industry practice this matters: Cognition's documented failure mode is parallel agents acting on incomplete information producing conflicting decisions — and the canonical example is creative assets in mismatched styles. Here the failure is worse: Agent 07 computes a creative blueprint and Agent 08 never receives it, so they are not even conflicting — they are unaware of each other.

## Architecture Problems

1. **14 competing orchestrators**, with **non-overlapping safety properties**: the production path lacks the compliance gate; the legacy path has the gate **but auto-publishes to X** (`autonomous_orchestrator.py:657-670`), violating the stated no-auto-publish invariant.
2. **63% dead code** (≈165/263 Python files).
3. **No durable execution.** `/api/run` spawns a subprocess and awaits `child.on('close')` — the documented anti-pattern. No journal, no resume, dies with the handler/deploy/timeout.
4. **Model tier is silently downgraded.** `vertex_spend_proxy.py:66` rewrites `gemini-3.8-flash` → `gemini-2.5-flash`, so the system reports a model it did not run.

## Visual Architecture Redesign

The fix is not a better prompt or another agent. It is **restoring the spec→renderer boundary**.

```
Trend / Directive
   |  LLM
Strategic insight + narrative            (grounded, cited)
   |  LLM
Creative concept  (3 competing, real model calls — not literal dicts)
   |  DETERMINISTIC
Concept selection (novelty gate BLOCKS at 0.0 — does not ship clones)
   |  LLM -> STRUCTURED SPEC (JSON, schema-validated)
   |     grid, type scale, hierarchy, focal point, palette slice, copy blocks
   |  DETERMINISTIC  <- the boundary that is currently broken
HTML/CSS layout engine driven by design tokens
   |  image model (BACKGROUND TEXTURE ONLY — never text, never logo)
   |  DETERMINISTIC
Playwright render @2x -> PNG
   |  MULTIMODAL CRITIC  (real VLM, structured JSON defects)
   |  revision agent -> re-render     (hard cap 2-3 rounds; convergence stop)
   |  human review
```

**Which steps are which:**

| Step | Type | Why |
|---|---|---|
| Insight, narrative, concept | **LLM** | genuine creative divergence |
| Concept selection / novelty | **deterministic** | must be able to say no |
| Visual specification | **LLM -> validated JSON schema** | the LLM specs; it does not draw |
| Layout, typography, logo, disclaimer | **deterministic (HTML/CSS + tokens)** | pixel-exact, brand-safe, testable |
| Background texture | **image model** | the only place generation belongs |
| Render | **deterministic (Playwright/Remotion)** | reproducible given the same spec |
| Critic | **multimodal LLM, structured output** | must return defects, not a score |
| Revision | **LLM + deterministic re-render** | capped, convergence-detected |
| Final approval | **human** | Rule-of-Two compliance |

**Critic contract** — structured defects, not a number:

```json
{ "severity": "high", "issue": "headline overlaps focal object",
  "location": "top-right", "reason": "...", "fix": "...", "confidence": 0.94 }
```

Scored across composition (hierarchy, alignment, balance, whitespace, focal point), typography (readability, hierarchy, line length, contrast), brand (token conformance, premium feel), storytelling (concept clarity, metaphor, flow), motion (pacing, transitions, rhythm), technical (resolution, safe areas, overlaps, artifacts).

**Name it correctly:** this is **evaluator-guided iterative generation**, not reinforcement learning. No reward model is trained, no policy is updated. Calling it RL would repeat the pattern this audit is documenting.

## The most important question

> **Is Vanna operating a genuine autonomous 13-agent production content intelligence system, or primarily an orchestration shell around several LLM calls with incomplete grounding, observability, evaluation, agent communication, and visual generation?**

**The latter — and the evidence is not ambiguous.**

One metered model call per run. Ten of thirteen agents are rule tables or literal dicts. No message bus in the execution path. No claim gate in production. A reviewer that awards 35 of 100 points unconditionally and calls itself Gemini. A learning loop trained on one test record duplicated 44 times, adjusting weights that reset to 1.0 every process. A visual pipeline whose entire design system is unreachable code. 46% of completed runs have no record. A model tier reported as 3.8 while 2.5 runs. Spend invented from a stopwatch.

What is genuinely good, and worth keeping: the ingestion daemon, the image generation call, the metaphor rotation registry, `atomic_store.py`, the claim-safety gate's fail-closed rule loading, the novelty detector (which correctly identified the clones — it was simply ignored), and the absence of any auto-publish client in the production path.

The gap is not capability. It is that **the telemetry describes a system that was designed but never connected**, and nothing in the stack is able to detect the difference. Every quality gate returns a constant; every failure falls back to something that looks like success. That is the single pattern to fix first — not because it causes the worst outcome, but because while it persists, no other fix can be verified.
